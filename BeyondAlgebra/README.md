### 《密纹轨迹》游戏策划案（精简版）

> **📌 版本规则**：新版本不更改旧版本文件。每次修改创建新的独立版本文件。详见 [`EDITION.md`](EDITION.md)。
> **当前版本**：v2.17 起步 → 当前开发 **v9.26**（详见 [`EDITION.md`](EDITION.md)）。
>
> ⚠️ **本文是策划案，落后于实现。** 正文里的波次/数值/机制描述仍是早期设计（「波次」现在是「楼层」、真空期已删除、密文板三选一已改成属性三选一……）。
> 需要**当前**数值与公式时请看 [`VALUES.md`](VALUES.md)；需要**当前**玩法时看游戏内 `H` 键的机制图鉴。
> 第 4 节的两张密文板表已按 v9.23 源码校对过。

**游戏类型**：2D俯视角射击动作 + 轻塔防
**核心机制**：
1.  **行走轨迹**：移动生成可叠加的伤害/控场线，留存约6秒（360帧）。
2.  **密文板**：击杀/三选一/牌库获取，触发板+效果板两两组合成永久被动。手牌上限20张，满牌自动替换最老牌。
3.  **护盾机制**：玩家HP为核心护盾，优先承受伤害，归零后仍可行动。
4.  **波间整顿**：每波结束三选一卡牌，随后5秒真空期（可跳过）。
5.  **停走冲刺**：怪物1:2停走比（停顿短移动长），高速怪切换更频繁；10波后概率免除停顿，20波全冲刺。
6.  **BOSS战**：每10波出现👑BOSS（HP 5000×1.6^(W/10-1)），持续召唤爪牙，击杀掉2-3张牌。
7.  **指数狂飙**：难度1.16^(W-1)，成长速度翻倍。

**游戏目标**：保护核心据点（🏰），冲击最高波次。

### 1. 核心规则

#### 1.1 轨迹系统
- 玩家移动每2帧生成一段轨迹（长度6px），轨迹上限120段，超出后旧轨迹自动消失。
- 轨迹留存360帧（约6秒），前240帧完全可见，后120帧逐渐淡出。
- 怪物触碰轨迹持续受伤（初始伤害约1.5/帧 = buff基础1 + 波次增长 `log₂(W+1)×0.5`，冷却15帧），触发 `T06（怪触轨）`。
- 轨迹可通过被动叠加升级：`E06（轨迹升级）` 每层+1伤害、+2宽度。

#### 1.2 密文板系统
- **获取**：击杀怪物掉落（概率 `min(0.2 + 波次×0.005, 0.5)`，最高50%），从牌库手动选取，或每波结束时的**三选一奖励**。手牌**无上限**。
- **三选一奖励**：每波清空后弹出3张随机卡牌（触发/效果混合），玩家挑选1张加入手牌，奖励得分+15。
- **使用**：必须由1张**触发板**与1张**效果板**配对，点击"宣读组合"后两张牌均消耗，形成**永久被动**。同组触发+效果每宣读一次，被动层数+1。
- **平衡机制**：手牌中触发板与效果板数量需保持平衡（差值≤1），防止偏科。组合冷却600ms。
- **牌库**：无限抽取，所有类型触发板/效果板始终可用。
- **波间真空期**：每波结束后进入20秒（1200帧）整顿时间，玩家可自由移动铺轨、组合卡牌、从牌库抽牌。倒计时结束后自动进入下一波，也可点击"跳过"按钮立即开战。

#### 1.3 流程与胜负
- **流程**：开局赠送2张密文板（1触发+1效果）→ WASD移动铺轨 + 自动射击清怪 → 拾取/选取密文板 → 组合形成被动 → 清空当前波次 → 🎴三选一卡牌 → ⏳5秒真空整顿（可跳过）→ 下一波（难度递增）。
- **护盾机制**：玩家HP为🛡️护盾。怪物触核时优先扣除护盾，护盾归零后玩家仍可正常行动（移动/射击），但再受攻击将直接损伤核心HP。护盾可受T10（残血触发）、E03（生命回复）等生命相关效果影响。
- **胜利（无限模式）**：无预设终点，冲击最高波次与得分。
- **失败**：核心据点HP归零（仅在护盾耗尽后才会发生）。

#### 1.4 停走交替机制
- 所有怪物以**1:2停走比**交替行进：静止1/3周期 → 移动2/3周期（停顿短、冲刺长）
- 移动阶段速度为原有的**2倍**，平均有效速度为原来的4/3
- 不同怪物有不同的全周期（见怪物表），高速怪物切换更频繁
- W≥10后，怪物有概率**完全免除停顿**全程冲刺：概率=`min(10%+9%×(W-10), 100%)`，W≥20全部冲刺
- 分裂子体统一使用40帧快节奏

### 3. 指数增长公式（无限模式）

所有公式基于波次 `W`（wave），难度系数 `D = 1.16^(W-1)`（每波+16%，成长翻倍）：

| 参数 | 公式 | 说明 |
|:--|:--|:--|
| **难度系数** | `D = 1.16^(W-1)` | 每波+16%，成长翻倍 |
| **怪物数量** | `min(4 + ⌊3 × 1.10^W⌋, 50)` | 指数增长，上限50只 |
| **精英概率** | `min(0.05 + 0.04 × log₂(W+1), 0.35)` | 上限35% |
| **生成间隔** | `max(6, 25 / 1.06^(W-1))` 帧 | 下限6帧 |
| **怪物HP** | `(基础HP + HP成长 × (精英?1.5:1)) × D` | 上限5000（BOSS 80000） |
| **怪物速度** | `(基础速度 + 速度成长 × (精英?1.2:1)) × min(D, 3.0)` | 移动时×2，平均×4/3 |
| **同时生成数** | `min(1 + ⌊W/12⌋, 3)` | 高波次可同时生成多只 |
| **卡牌掉落率** | `min(0.2 + W × 0.005, 0.5)` | 上限50% |
| **BOSS HP** | `50000 × 1.6^(⌊W/10⌋-1)` | 上限800000 |
| **持续移动率** | `min(10% + 9%×(W-10), 100%)` | W≥10生效，W≥20全冲刺 |

> 每5波清空后额外得分 `W×15`。

### 5. 被动叠加系统

#### 5.1 核心逻辑
- 每宣读一组"触发板+效果板"组合 → 该组合成为**永久被动**，计数+1。
- 每次宣读新增被动时，奖励得分+10。
- 游戏中触发条件满足时 → 该触发板下所有效果板**各执行其层数次**。
  - 例：`T07（射击命中）` 下绑定了 `E01×3 + E02×2`，则每次射击命中 → 攻击+5×3次=+15，倍率+0.2×2次=+0.4。

#### 5.2 当前Buff上限参考
| Buff | 每层增量 | 无上限 |
|:--|:--|:--|
| 攻击力 | +5 | 是 |
| 倍率 | +0.2 | 是 |
| 轨迹伤害 | +1 | 是 |
| 轨迹宽度 | +2px | 是（初始6px） |
| 移速加成 | +30% | 是 |
| 怪物减速 | +20%/层 | 否（最终减速=层数×20%×30%） |

### 8. 流派与模式

#### 8.1 两大战斗流派
- **疾行连击流（动作向）**：高频走位铺轨，搭配 `T07（射击命中）+E02（连环击）` 和 `T08（连杀）+E11（自速暴涨）`，越打越快、越打越强。
- **固线守御流（塔防向）**：绘制闭环轨迹构建防线，搭配 `T06（怪触轨）+E06（轨迹升级）/E13（冰冻）`，让怪物在轨迹中举步维艰（轨迹本身踩上去就迟缓 3 秒）。

#### 8.2 拓展模式
- **✅ 无限模式（已实装）**：怪物无限波次，每波难度×1.08指数增长。怪物数量、精英概率、属性持续攀升。冲击最高波次与得分。
- **📋 据点坚守（规划中）**：多路线防守，优先强化墙体类密文板。
- **📋 双人合作（规划中）**：双人轨迹可拼接，手牌独立，分工配合。

### 10. 数值设计原则

1. **指数增长**：难度系数1.08^W 保证前期可发育、中期需策略、后期极限挑战。
2. **软上限**：怪物HP/攻击/速度有硬上限（5000/80/5.0），防止数值溢出。
3. **被动永续**：所有组合均为永久被动，鼓励玩家尽早组合、持续叠加。
4. **平衡约束**：手牌触发/效果数量差≤1，防止单边堆积；手牌无上限，消除库存焦虑。
5. **奖励递增**：每5波额外奖励 + 每波三选一 + 波次清空加分，多重激励机制。
6. **连击系统**：得分连击提供倍率加成，奖励连续高效操作。
7. **护盾缓冲**：玩家HP作为核心护盾，归零后仍可行动，给予极限翻盘空间。
8. **波间整顿**：20秒真空期供玩家铺轨布防、组合卡牌，策略深度与操作空间并存。
9. **怪物慢节奏**：移速/4、血量×3，让轨迹伤害有充分时间发挥，强调策略而非反应速度。
