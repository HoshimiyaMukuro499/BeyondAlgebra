## v9.12 — 网格判环+视觉完善

**文件**：`密文轨迹demo9.12.html`
**基于**：v9.11

### 判环算法：网格法（Xonix式，来自 StackOverflow/GameMaker 社区研究）

旧方法：路径点距离<30px判断 → φ形等自交环判定失败
新方法：
1. 画布等分20×20px网格单元
2. `_grid[gx+','+gy]` 记录每个格子首次被访问的游戏帧数
3. 每3帧采样玩家坐标入 `_path[]`
4. 重新进入60帧前标记的旧格子 → 判定路径自交
5. 在 _path 中定位旧帧对应的路径索引
6. 提取该索引到末尾作为环路径 → Shoelace面积
7. 多边形质心公式精确定位环中心
8. 面积>800px² → 闭环成立 → 召唤图腾
9. 清除网格数据，保留最近10个路径点防重复触发

### 图腾视觉完善

- 射程虚线指示圈（setLineDash）

- 命中爆炸粒子+炮口闪光
- 菱形石刻基座+地面椭圆投影+呼吸脉冲核心
- 五种图腾类型：基础/速射/雷电(连锁)/冰霜(冻结)/轨迹(脉冲AOE)

## v9.11 — 画图召唤：轨迹闭环→图腾

**文件**：`密文轨迹demo9.11.html`
**基于**：v9.10

### 核心机制：密文+轨迹交织

> 玩家用移动在地面"写"出图案。密文板决定这个图案产生什么效果。

**操作 → 触发 → 结果链：**

| 轨迹动作 | 触发板 | 效果板 | 结果 |
|---------|--------|--------|------|
| 画闭环(>1500px²) | T12 闭环 | E01 攻击 | 速射图腾 |
| 画闭环 | T12 闭环 | E12 闪电 | 雷电图腾(连锁) |
| 画闭环 | T12 闭环 | E13 冰冻 | 冰霜图腾(冻结) |
| 画闭环 | T12 闭环 | E06 轨迹 | 轨迹图腾(脉冲AOE) |
| 无被动 | — | — | 基础图腾 |

**闭环检测规则：**
1. 用轨迹围成一个区域（Shoelace公式计算面积）
2. 面积 > 1500px² → 小闭环（🥉 0.6倍强度）
3. 面积 > 8000px² → 大闭环（🥇 1.5倍强度）
4. 当前位置需接近旧轨迹（距离<70px = 闭环成立）
5. 冷却90帧（1.5秒），防止连续触发
6. 最多同时3个图腾，超出则移除最旧的

**图腾属性：**
- 自动射击范围内最近怪物
- 存活时间约10秒（基础图腾600帧）
- 大环图腾射速更快、伤害更高

**卡牌经济修复：**
- 楼层清空：固定1张牌（每3层2张），不再依赖击杀数
- 移除击杀随机掉卡（解决"早期没牌/后期泛滥"）

### 新增
- **T12 闭环触发板**：轨迹围成闭环时触发效果
- **5种图腾**：基础/速射/雷电/冰霜/轨迹
- **闭环检测算法**：Shoelace面积公式 + 首尾距离判定
- **图腾渲染**：光环+emoji+血条

### 减法

## v9.10 — 自动模拟模式+AI驾驶+自主优化Loop

**文件**：`密文轨迹demo9.10.html`
**基于**：v9.9

### 核心创新：自主开发-试玩-优化闭环

游戏现在可以**自动驾驶、自动决策、自动输出结构化数据**，配合 Node.js 运行器和分析引擎，形成无需人工操作的数值平衡迭代循环。

### 自动模拟模式 (URL: `?auto=30&speed=5`)

#### 模拟模式特性
- URL参数 `?auto` 开启模拟，`?auto=N` 限N层，`&speed=N` N倍速
- 跳过所有DOM渲染和视觉特效（粒子/浮动文字/通知）
- 用 `setTimeout` 替代 `requestAnimationFrame`，不受60fps限制
- 每tick跑 `simSpeed` 次 `update()`（3x=3帧/tick）

#### AI 自动驾驶 (autoPilot)
- **默认轨道巡逻**：绕核心100-130px半径画圈（`sin`调制）
- **闪避模式**：非虚灵怪物靠近90px时远离
- 始终按住Shift冲刺（厚轨迹=高伤害+阻挡）

#### 6个自动决策函数
| 函数 | 策略 |
|------|------|
| `simAutoSelectClass()` | 优先轨迹编织者（轨迹=核心输出） |
| `simAutoStatChoice()` | 评分制：轨迹淬炼>攻击强化>疾步>回血(HP<40%) |
| `simAutoNodeMap()` | 评分制：低血→休整/商人，一般→精英，必打BOSS |
| `simAutoMerchantVisit()` | 自动购物：治疗>便宜卡牌>遗物>精华 |
| `simAutoFateChoice()` | 评分制：轨迹大师>铁壁>弹幕风暴>超载 |
| `simAutoCombine()` | 每30帧自动组合同类型手牌 |

#### JSON导出
- `exportGameLogJSON()` 输出结构化JSON（summary+events数组）
- `handleSimGameOver()` 写入 `window.__SIM_RESULT__` 和 `<pre#simResult>`
- 控制台输出 `===SIM_RESULT===` 标记便于抓取

### 新建配套工具

| 文件 | 说明 |
|------|------|
| `simRunner.js` | Node.js + Puppeteer 模拟运行器 |
| `sim.bat` | Windows 快捷运行脚本 |
| `analyzeSim.js` | 结果分析引擎（10项指标+调整建议） |

### 分析指标
- 最终楼层、难度曲线、攻击力增长、力量尖峰检测
- 轨迹vs攻击对比、轨迹宽度、HP曲线、治疗使用频率
- 死亡分析、轮椅组合统计

### Loop 工作流
```
node simRunner.js 50 5 → sim_results.json
    ↓
node analyzeSim.js sim_results.json
    ↓
Claude Code 读取分析 → 提出调整 → 写入HTML → 重跑验证
```

## v9.7 — 轨迹阻挡+围剿伤害+蜿蜒地图+冲刺轨迹 · 动作革命

**文件**：`密文轨迹demo9.7.html`
**基于**：v9.6

### 核心理念转变
"密文轨迹"名称的"轨迹"二字终于成为核心动作机制——轨迹不只是被动残留，而是主动武器。用轨迹围堵怪物、冲刺留下烈焰轨迹、蜿蜒地图记录冒险路径。

### 五大动作革命

#### 1. 🧱 轨迹阻挡怪物（核心机制革命）
- **怪物无法穿越轨迹**：轨迹成为战场上的动态墙壁
- 怪物检测前方轨迹→自动绕行（绕行角度±1.5rad，速度×0.5）
- 玩家可以用轨迹引导怪物走向、分割战场、保护核心
- 轨迹宽度越大，阻挡效果越强（冰轨永冻宽度×1.5效果最明显）

#### 2. 🔒 围剿系统
- 每30帧检测：怪物周围8方向是否有≥6方向被轨迹封锁
- 围剿成功→25+轨迹伤害×3+楼层数的伤害+眩晕30帧
- 视觉反馈：🔒图标浮动数值+金色粒子
- 轨迹越密、走位越精准，围剿越容易触发

#### 3. 💨 冲刺轨迹（Shift键）
- 按住Shift移动→留下冲刺轨迹（更宽×1.5、更亮、留存90帧）
- 冲刺轨迹伤害×2.5，冷却仅8帧
- 冲刺轨迹独立渲染：大光晕(35px blur)、高alpha
- 上限60段冲刺轨迹，消耗战资源

#### 4. 🗺️ 蜿蜒地图（Canvas绘制）
- 地图不再用HTML弹窗，直接在游戏Canvas上绘制
- **蜿蜒小径**：根据pathHistory（左/中/右选择）弯曲路径
  - 选左边→路径向左弯
  - 选中间→路径竖直
  - 选右边→路径向右弯
- 已走过的节点：暗色圆点带图标
- 当前节点：金色高亮
- 3个分支节点：悬停高亮，点击选择
- 路径用虚线连接，体现"冒险轨迹"
- 操作提示在底部

#### 5. 🎯 轨迹伤害强化
- 冲刺轨迹伤害×2.5（鼓励主动冲刺围剿）
- 冲刺轨迹命中冷却8帧（vs普通15帧）
- 浮动数值在冲刺命中时显示金色

### 动作玩法循环
```
移动布轨→轨迹阻挡怪物绕行→冲刺围剿→🔒包围伤害→
清场→选卡→蜿蜒地图选关→下一层
```

### 面板更新
- 标题：9.7 · 轨迹阻挡+围剿+蜿蜒地图+冲刺
