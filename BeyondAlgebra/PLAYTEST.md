# 4.0 真人试玩记录表

一页纸，一次三个人。**目标不是评价游戏，是找出「该砍的」和「该教的」。**

## 前提（不满足就别开始）

- **必须用默认配置**：直接双击 `密文轨迹demo4.0.html`，**不要**加任何网址参数，
  也不要把上次点过的开关留着。测的是「减法版」，配置一旦不是默认，测的就是 9.32。
  （要回到默认：面板底部「全关」，或者地址栏敲一次 `?flags=none` 再删掉参数。）
- **对象**：3 位**没玩过这个游戏**的人。玩过 9.x 的人不算。
- **每位 15 分钟**，一次一位，不要凑在一起互相看。
- **全程不说话、不提示、不救场。** 卡住了就看着，不要说「按 F」。他放弃了就结束这一轮。

## 只记这四个数

| # | 记什么 | A | B | C |
|:--|:--|:--|:--|:--|
| ① | **第一次死在几层** | | | |
| ② | **第一次卡住是在做什么**（一句话，记具体动作） | | | |
| ③ | **第一句「这是什么意思」问的是什么**（原话） | | | |
| ④ | **第一句「我不想玩了」出现在第几分钟**（没出现就写「无」） | | | |

③ 和 ④ 记**原话**，别翻译成你的归纳——归纳留在下一节的「共同点」里做。

## 三个人的记录下面，加一节「共同点」

只写**至少两个人身上都出现**的东西：

- 三个人都卡在同一件事 → 那件事要么该砍，要么该教。（先想「能不能砍」。）
- 三个人都在同一层左右死 → 前若干层的难度曲线偏陡，或核心循环没被讲明白。
- 三个人都问了同一个名词 → 那个名词要么改名，要么第一次出现时就地解释。
- 有人 15 分钟内没出现过 ④ → 这一版的核心循环及格了。

## 附：想汇总的话

四行 JSON 就够（每行一位）：

```json
{"who":"A","min":15,"first_death_floor":7,"stuck":"想把两张牌合起来但不知道点哪","first_question":"图腾是什么","quit_at_min":null}
```

`quit_at_min` 没出现就写 `null`。跑完把三行贴一起，就是这一版的试玩结论。
