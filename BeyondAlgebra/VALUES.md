## 1. 难度与波次生成

### 难度系数（全局乘子）

`01-state.js:144-150`

```
DIFF_KNEE = 30        // 拐点：30 层前纯指数，之后转多项式
DIFF_TAIL = 1.6

D(f) = 1.16 ^ (min(f, 30) - 1)  ×  max(1, f / 30) ^ 1.6
```

- 30 层前与原公式完全一致：10 层 ×3.80，20 层 ×14.5，30 层 ×55.1
- 118 层：旧曲线 ×34,800,440 → 新曲线 ×687
- UI 上以 `×D` 的两位小数显示（右下角 + 面板 `diffDisplay`）

### 每层怪物数

`01-state.js:152-154`

```
getMonsterCount() = floor( min(4 + floor(3 × 1.10^f), 50) × monsterCountMul )
```

硬顶 **50 只**。`monsterCountMul` 来自命运「丰收」×1.25 与遗物「贪婪圣杯」×1.3。

### 精英概率

`01-state.js:156-160`

```
base  = min(0.05 + 0.04 × log2(f + 1), 0.35)
final = min(base × eliteMult, 0.8)
```

`eliteMult` = 2.5（仅 `eliteSquad` 关卡类型）。`forceEliteWave` 会强制 1.0（该字段无写入点，见 §15）。

### 出怪间隔与批量

`01-state.js:181-185`、`05-update.js:589-594`

```
getSpawnInterval() = max(6, 25 / 1.06^(f - 1))      // fastRush 关卡 ×0.4
每次生成数量        = min(1 + floor(f / 12), 3)
```

出怪点：从画布外四边随机（`pad = 30`）。`ambush` 类型例外——围绕核心 `rand(120, 200)` 距离（该类型已不在 `STAGE_TYPES` 中）。

### 精英词缀数量

`01-state.js:188-199`，词缀池开放门槛 `minWave = 5`（**14 个词条全部 minWave = 5**）

| 楼层 | 数量 |
|:--|:--|
| f < 5 | 0 |
| 5 ≤ f < 15 | 30% 出 1 个，否则 0 |
| 15 ≤ f < 25 | 1 个；30% 变 2 个 |
| f ≥ 25 | 2 个；20% 变 3 个 |

BOSS 不按上表——`spawnBoss()` 固定 `pickAffixes(2, ['dash', 'swarm'])`，
即**恰好 2 个**，且排除突进与群生。

### 关卡类型权重

`00-data.js:239-247`。每种怪在 `mixed` 下的基准权重见下（实际生效值 = `权重 × 10`，因为无定义时回落到 `MONSTER_TYPES[].weight`）：

## 3. 子弹

`04-trail.js:38-84`、`05-update.js:141-181`

### 两道独立闸门（改射速必须两处都动）

```
G.fireRate        = 40   （几帧打一发）          01-state.js:14
p.shootCooldown   = max(24, 48 - f × 0.32)      04-trail.js:83
```

实际间隔不是两者之和，而是**「≥ 冷却的 fireRate 最小整数倍」**：射速闸每满 `fireRate` 帧才问一次冷却，冷却没走完就白问一次（`fireCounter` 已经归零）。

```
冷却 ≤ fireRate        → 间隔 = fireRate
fireRate < 冷却 ≤ 2×fr → 间隔 = 2 × fireRate
```

第 1 层冷却 47.68 > 40 → **80 帧一发**；第 25 层冷却降到 40 → **40 帧一发**。所以手感在第 25 层会突然快一倍——这是 v9.19 把两处同时 ×4 保留下来的既有结构，不是新 bug。

职业修正：弹幕风暴 `fireRate ×0.6`，堡垒守卫 ×1.25。连锁风暴「-8」（`fireRate = max(12, fireRate - 8)`）也会把间隔从 40 压到 32。

### 单发伤害

```
atk = (player.atk + buffs.atkUp) × (1 + buffs.multUp) × fateBuffs.atkMul
      × fateBuffs.bulletDmgMul × 1.15
if (低血狂暴 && hp < maxHp × 0.3)  atk ×= 2      // 遗物·狂战图腾
if (rand < critChance)             atk ×= 2      // 遗物·暗影之刃，20%
```

`buffs.multUp` 是**加法**累积（每层 +0.25，上限 49），显示为 `×(1+multUp)`。

### 弹体参数

| 项 | 主弹 | 额外弹丸 |
|:--|:--|:--|
| 速度 | 7 | 7 |
| 半径 | 4 | 3 |
| 寿命 | 60 帧 | 50 帧 |
| 伤害 | `atk` | `atk × 0.6` |
| 散射 | ±0.08 弧度 | ±0.2 弧度 |
| 出膛偏移 | 22px | 22px |

额外弹丸数量 = `G.extraBullets`（弹幕风暴职业 +1）。出界判定 `x < -10 || x > 790 || y < -10 || y > 570`。

### 命中效果

- 虚灵减伤：`bulletDmg × (1 - bulletResist)`，`bulletResist = 0.3`
- **停顿 18 帧**（0.3s，`m.stunned`），BOSS 也吃
- 每颗子弹首次命中 +1 分，并触发 T07；命中精英/BOSS 额外触发 T03
- v9.22 起**命中不再给终极技充能**（改固定时间回复，见 §8）

### 索敌优先级

`04-trail.js:44-45`：治疗 💚 → 精英 ⭐ → BOSS 👑 → 其余；同类里取最近。

## 4. 轨迹与冲刺

`04-trail.js:86-98`、`05-update.js:109-119`

| 项 | 值 |
|:--|:--|
| 生成频率 | 每 2 帧（仅移动时） |
| 段长 | 6px（两端各 ±6） |
| 基础寿命 | 360 帧 + `trailLifeBonus` |
| 基础宽度 | 6 |
| 冲刺段长 | 12px |
| 冲刺寿命 | 180 帧 |
| 冲刺宽度 | `(宽度 + 4) × 类型倍率 × 1.5` |

`trailLifeBonus` 来源：轨迹编织者 +180、遗物「时间膨胀器」+120。

### 轨迹伤害

```
getTrailDamage() = (buffs.trailDmg + log2(f + 1) × 0.5) × fateBuffs.trailDmgMul
```

`buffs.trailDmg` 初始 **1**，上限 100（E06）。冲刺命中 **×2.5**。

### 踩踏判定与冷却

```
命中判定：dist(m, 段中点) < getTrailWidth() + m.r + 10
伤害冷却：普通 15 帧 / 冲刺 8 帧     （每个怪独立，m.trailDamageCooldown）
```

- **虚灵免疫轨迹伤害**（`isWraith`），但**不免疫迟缓**
- 每跳 +1 分，触发 T06；精英/BOSS 额外触发 T03
- v9.22 起轨迹伤害也不再给终极技充能

### v9.22 改动：轨迹不再阻挡

轨迹**不再**改变怪物移动（旧版是随机 ±1.5 弧度偏转 + 减速 0.5）。现在：

```
踩到轨迹 → m.slowTimer = max(m.slowTimer, 180)   // 3 秒
移速      × (0.8)  当 slowTimer > 0
```

`TRAIL_SLOW_FRAMES = 180`（`05-update.js:3`）。**无冷却**——踩着就一直续 3 秒，离开 3 秒后恢复。与 E14「延缓」**共用** `m.slowTimer` 和同一个 0.8 乘数，叠加时取更长的持续时间（**不叠乘**）。

轨迹类型外观（`00-data.js:260-265`）与宽度倍率：

| 类型 | 宽度倍率 | 触发 |
|:--|:--|:--|
| basic 蓝 | 1.0 | 默认 |
| fire 红 | 1.3 | 轨迹反噬 / 爆轨清场 |
| ice 白 | 1.5 | 冰轨永冻 |
| lightning 金 | 1.1 | 连锁风暴 / 弹幕地狱 |

### 围剿

`05-update.js:634-666`，每 30 帧检测一次（需 `trails.length > 10`）

```
对每只非 BOSS 怪：以 8 个方向、半径 (50 + m.r) 采样，
若某方向的点被轨迹覆盖（dist < trailWidth + 8）或出界 → 该方向算"堵"
堵住 ≥ 6/8 → 围剿：伤害 = 25 + buffs.trailDmg × 3 + f ，眩晕 30 帧
```

每 60 帧额外 +5 分。注意：这是**纯几何判定**，和物理碰撞无关，所以 v9.22 取消轨迹阻挡不影响它。

解锁门槛：灼烧怪 **第 8 层**起，虚灵怪 **第 12 层**起。

### 生成公式

```
hp  = (baseHp + hpScale)        × D × hpMult × 0.8  // 精英：(baseHp + hpScale × 1.5)
spd = (baseSpeed + speedScale)  × min(D, 3.0)       // 精英：speedScale × 1.2（不乘 0.8）
atk = (baseAtk + atkScale)      × min(D^0.35, 12) × 0.8   // 精英：atkScale × 1.3
```

硬钳：`hp ≤ 1e9`、`speed ≤ 6.0`、`atk ≤ 120`。

> **v9.24 起普通怪 HP 与攻击各 ×0.8**（`MONSTER_STAT_MUL`），**移速不动**——
> 出怪变密之后再削移速只会变成「又慢又肉又没威胁」，纯拖时间。
> 作用域仅 `spawnMonster()`；`spawnBoss()` / `spawnBossMinion()`（已 0.5×）/
> `spawnDebugMonster()` 与分裂子体、群生残影都**不**再乘一次
> （子体的数值从母体派生，母体已经吃过这一刀）。

`hpMult`：重装关卡 ×2；教程 `hpMul`（第 1 层 0.6）。

> **注意 `speed` 在生成时已乘过一次 `(1 - slowAll)`**（`02-combat.js:276`），而每帧更新时又乘一次（`05-update.js:205`）。这两处是历史遗留的重复计算，改减速相关数值时要留意。
> `atk` 的幂次是 **0.35**（不是刷新时的 4.0）——v9.15 改的，防止怪物伤害在第 10 层永久冻结在 24 点。

### 每帧移速

`05-update.js:205`

```
spd = m.speed × (1 - slowAll) × (slowTimer > 0 ? 0.8 : 1) × 1.33
```

> `× 1.33` 是全局速度补偿系数，硬写在公式里。改怪物手感要在这里调，不要去改 `baseSpeed`（那会同时改生成时的那次计算）。

`disabled`（frozen > 0 或 stunned > 0）时完全不移动、不攻击、不出火轨。

### 索敌

`05-update.js:197-200`：在**最近的图腾**与**核心**之间挑更近的那个（`nearestTurret`，`04-trail.js:215-222`）。

## 13. 地形 / 危险区 / 关卡结构

### 地形障碍

`00-data.js:454-474`，**每 3 层重建一次**（`04-trail.js:28`）。

```
count    = 3 + floor(f / 8)
半径 r   = rand(20, 50)
位置     = rand(40, w-40), rand(40, h-40)    // w=780, h=560
安全区   = 核心周围 r < 80 + tr + 20 的位置被重掷（最多 20 次尝试）
寿命     = f × 60 + 600 帧
alpha    = 0.4（渲染时再 × min(1, life / 300)，即最后 5 秒淡出）
```

第 3 层：3 个障碍，寿命 780 帧（13 秒）。第 24 层：6 个，寿命 2040 帧（34 秒）。

**玩家碰撞**（`05-update.js:99-105`）：向外投影到圆面上，余量 `p.r + t.r + 2`。

**怪物绕行（v9.22）**：`steerAroundTerrain()`（`05-update.js:28-63`）
1. 先把陷进障碍的实体沿法线顶出来（`pushOutOfTerrain`，余量 `m.r + 2`）
2. 找「下一步陷得最深」的那一个障碍
3. 取该圆的切线，两条里挑与「怪→目标」夹角更小的那条
4. 切线方向 + 朝目标方向 ×0.45，归一化后乘回原速度
5. 移动之后再兜一次底 `pushOutOfTerrain`

> 旧做法是随机 ±1.2 弧度偏转 + 速度 ×0.6，有一半概率把怪推进墙里，且贴墙后完全忽略目标方向 → 原地打转。v9.22 换成确定性切向绕行。

```
每 900 帧（15 秒）生成一个，场上最多 5 个
r = 55，life = 600 帧（10 秒）
位置 = rand(80, 700), rand(80, 480)
玩家：1.2 / 帧      怪物：4 / 帧
```
